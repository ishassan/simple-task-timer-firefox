# Simple Task Timer (Firefox)

A Firefox fork of the Chrome extension "Task Timer".

Firefox Add-ons page: https://addons.mozilla.org/en-US/firefox/addon/simple-task-timer/

## Original author

Task Timer was created by **Schuyler Cebulskie (Gawdl3y)**.
This project started from his code, and most of it is still his work:

- Chrome source: https://github.com/Gawdl3y/task-timer-chrome
- Older repo (Chrome and Android): https://github.com/Gawdl3y/task-timer-legacy
- Chrome Web Store ID: aomfjmibjhhfdenfkpaodhnlhkolngif

## This is a fork

This is an independent fork, not an official version of Task Timer.
It does not try to match the Chrome extension. Features may be added,
changed, or removed here without following the original.
